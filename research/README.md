# Craniofacial representation learning: training and evaluation for rare disease diagnosis

This tree contains the first-party executable research source used during model development. Directory dates identify experimental iterations. The selected route is **TransFace-L → CHOP patient-identity ArcFace adaptation → GMDB disease ArcFace fine-tuning → HPO modeling and gated cross-attention diagnosis**. Earlier DINO/SSL experiments and alternative fusion methods are included as development history, not interchangeable stages of that route.

The archive includes data-preparation code, model definitions, training and evaluation loops, tests, multi-seed orchestration, resource controllers, report-generation code and release builders. Historical runtime JSON/YAML, patient records, split membership, image caches, checkpoints, feature arrays, clinical notes, outputs and credentials remain local. Numeric hyperparameters are provided separately in [TRAINING_PARAMETERS.json](TRAINING_PARAMETERS.json), extracted using an explicit numeric-field allowlist. Third-party source trees and installed environments are dependencies rather than duplicated package installations.

## How to read an experiment directory

- `prepare*.py`, `extract.py`, `cache*.py`: build local inputs and provenance receipts.
- `model.py`, `network.py`, `data.py`: architecture, loss and sampling behavior.
- `protocol.json`, `cases.json`, YAML: locally generated runtime settings consumed by the programs; these historical files are withheld. The public numeric parameter templates and configuration-generation code document the training settings.
- `train.py`, `train_rank.py`: optimization and checkpoint-resume logic.
- `evaluate.py`, `score.py`, `validation.py`: metrics, patient aggregation and comparisons.
- `controller.py`, `run.py`, `.sbatch`: original orchestration, requiring site-specific adaptation.
- `test_*.py`: synthetic unit tests and, in some directories, private-data integration tests. Do not run the entire archive's test discovery against a public checkout.

Repeated seed folders and backup snapshots are retained to preserve source history. They are not additional independent methods. [SOURCE_INDEX.md](SOURCE_INDEX.md) lists every included group; [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) records original and exported source hashes and whether deployment references were normalized.

## Current scientific scope

The stable inference release provides facial-only, HPO-only and multimodal diagnosis plus optional independent-branch retrieval. The agent and variant programs are research modules, not part of that deployment bundle. Public variant annotations are not patient variant detections. Unknown HPO observations are not negative findings.

Historical CHOP HPO experiments include unresolved-polarity inputs; consult the clinical readiness audit before treating them as evidence of clinical multimodal benefit or harm. Selecting policies or checkpoints on development data does not make those results independent test evidence. External evaluation requires patient overlap checks and a frozen model and evaluation protocol.
